# Website setup

Open `index.html` in a browser to preview locally. For deployment, upload the entire `website` folder; the logo is included in `website/assets/`.

Before launch, edit `app.js`:
- `SHOP.phone`
- `SHOP.whatsapp`
- `SHOP.address`
- `SHOP.hours`
- `SHOP.mapsUrl`
- `SHOP.rates`
- `PRODUCTS` and `BANNERS`

Demo products and image links are illustrative. Replace them with shop-approved photos and product details. The website is not connected to the Android app in this version.
